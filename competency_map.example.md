# Карта подтверждённых кейсов

Это синтетический пример структуры. Замените его своими фактами до подключения.
Раздел кейса должен начинаться с `### 1. ...`; название после номера должно точно
совпадать с `projects[].name` в профиле. Общие указания вне кейсов не используются.

### 1. Учебный каталог (синтетический пример)

Личная задача: поиск и фильтрация записей на Python и SQLite.
Стадия: учебный проект. Коммерческий запуск, сроки, нагрузка и бизнес-метрики не подтверждены.
